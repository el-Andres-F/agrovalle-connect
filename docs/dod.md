# Definition of Done — AgroValle Connect

## Objetivo

La Definition of Done (DoD) establece las condiciones que debe cumplir una Historia de Usuario para considerarse completamente terminada y lista para ser integrada al proyecto.

## Checklist de calidad

Una Historia de Usuario se considera terminada cuando cumple todos los siguientes criterios:

- [ ] La funcionalidad fue desarrollada de acuerdo con la Historia de Usuario.
- [ ] Los criterios de aceptación definidos en BDD fueron cumplidos.
- [ ] El código compila correctamente.
- [ ] Se realizaron las pruebas correspondientes.
- [ ] Las pruebas ejecutadas fueron satisfactorias.
- [ ] El código cumple las reglas definidas en `checkstyle.xml`.
- [ ] Se realizó revisión de código por otro integrante del equipo.
- [ ] El cambio fue gestionado mediante un Pull Request.
- [ ] El Pull Request fue revisado y aprobado antes del merge.
- [ ] Los commits utilizan la convención Conventional Commits.
- [ ] La documentación relacionada con la funcionalidad fue actualizada cuando fue necesario.
- [ ] La funcionalidad fue integrada correctamente a la rama correspondiente.
- [ ] No existen errores conocidos que impidan considerar terminada la Historia de Usuario.

## Criterio final

Una Historia de Usuario solamente podrá considerarse **Done** cuando todos los criterios anteriores hayan sido cumplidos.
